# Internationalization (i18n)

Audiobookphile supports **21 languages** out of the box using `next-intl`.

---

## 1. Supported Languages

| Code | Language | Code | Language |
|---|---|---|---|
| `en` | English (Default) | `es` | Spanish |
| `fr` | French | `de` | German |
| `it` | Italian | `pt` | Portuguese |
| `ru` | Russian | `zh` | Chinese (Simplified) |
| `ja` | Japanese | `ko` | Korean |
| `ar` | Arabic (RTL) | `hi` | Hindi |
| `nl` | Dutch | `pl` | Polish |
| `sv` | Swedish | `no` | Norwegian |
| `da` | Danish | `fi` | Finnish |
| `tr` | Turkish | `uk` | Ukrainian |
| `el` | Greek | | |

---

## 2. Directory Structure

Translations are organized in JSON files under `messages/`:

```
messages/
├── en.json       # Base English dictionary (source of truth)
├── es.json
├── fr.json
└── ...
```

---

## 3. Usage in Components

### Client Components
```tsx
'use client';
import { useTranslations } from 'next-intl';

export function PlayerControls() {
  const t = useTranslations('Player');
  return <button aria-label={t('play')}>{t('play')}</button>;
}
```

### Server Components
```tsx
import { getTranslations } from 'next-intl/server';

export default async function LibraryPage() {
  const t = await getTranslations('Library');
  return <h1>{t('title')}</h1>;
}
```

---

## 4. Adding or Syncing Localization Strings

1. Add the new key-value pair to `messages/en.json`.
2. Sync the key to other languages or provide machine translations.
3. Validate bundle integrity:
   ```bash
   bun run typecheck
   bun test
   ```
